# Art 美术设计

## 风格方向

- **可爱风**，明亮活泼
- 参考：《泡姆泡姆》圆润造型、《糖豆人》Q版比例
- 角色：圆润豆子人/胶囊体
- 方块：糖果色，软边

## 角色

- 占位：Capsule + Sphere（约1格高）
- 正式：Q版豆子人
- 动画：行走 / 跳跃 / 飞行 / 交互

## 场景

- 棋盘：半透明网格 + 发光边框
- 背景：柔光天空盒 / 渐变
- 特效：消除粒子爆发 / 方块掉落轨迹 / 技能光效
