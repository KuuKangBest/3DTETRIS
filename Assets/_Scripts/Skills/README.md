# Skills 技能系统

## 架构

所有技能实现 `ISkill` 接口，由 `SkillSystem` 统一管理：

```
ISkill
├── SkillID        # 唯一标识
├── DisplayName    # 显示名称
├── Description    # 描述
├── Cooldown       # 冷却时间(秒)
├── IsReady        # 是否就绪
├── Activate()     # 激活技能
├── Tick(dt)       # 每帧更新
└── ResetCooldown() # 重置冷却
```

## 已实现技能

| 技能 | ID | 冷却 | 效果 |
|------|-----|------|------|

## 添加新技能

1. 创建新脚本实现 `ISkill`
2. 在 SkillSystem 上调用 `RegisterSkill(skill, hotkey)`
3. 添加到 GameUI 冷却显示
