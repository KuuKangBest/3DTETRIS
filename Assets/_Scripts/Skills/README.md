# Skills 技能系统

## 架构

所有技能实现 `ISkill` 接口，由 `SkillSystem` 统一管理：

```
ISkill
├── SkillID        # 唯一标识
├── DisplayName    # 显示名称
├── Description    # 描述
├── Cooldown       # 冷却时间(秒)
├── IsReady        # 是否就绪
├── Activate()     # 激活技能
├── Tick(dt)       # 每帧更新
└── ResetCooldown() # 重置冷却
```

## 已实现技能

| 技能 | ID | 冷却 | 效果 |
|------|-----|------|------|
| 推动方块 | push_block | 3s | 沿视线方向推动活动方块一格 |
| 清除方块 | clear_block | 8s | 清除前方 1.5m 半径内的已放置方块 |

## 规划技能

| 技能 | 设想 |
|------|------|
| 飞行/喷射 | 限时飞行移动 |
| 冻结方块 | 暂停方块掉落 N 秒 |
| 炸弹消除 | 大范围清除 |
| 远程旋转 | 远程旋转活动方块 |
| 瞬移 | 快速移动到指定位置 |
| 连锁消除 | 触发额外消除奖励 |

## 添加新技能

1. 创建新脚本实现 `ISkill`
2. 在 SkillSystem 上调用 `RegisterSkill(skill, hotkey)`
3. 添加到 GameUI 冷却显示
