# Player 玩家系统

## 视角与控制

| 项目 | 按键 | 说明 |
|------|------|------|
| 视角 | 第三人称 | 糖豆人风格 |
| 移动 | WASD | 行走 (walkSpeed=5) |
| 冲刺 | LeftShift | 加速 (sprintSpeed=8) |
| 跳跃 | Space | 基础跳跃 |
| 视角旋转 | 鼠标 | 水平+俯仰 |
| 飞行 | F | 限时飞行（需解锁） |
| 推动方块 | 鼠标左键 | 视线方向推一格 |
| 清除方块 | 鼠标右键 | 范围消除（需技能） |

## 能力

| 能力 | 状态 | 参数 |
|------|------|------|
| 走路 | ✅ 内置 | 5m/s |
| 冲刺 | ✅ 内置 | 8m/s |
| 跳跃 | ✅ 内置 | 8m/s² |
| 飞行 | 🔓 技能 | 3s持续 / 5s冷却 |

## 与方块交互

- 玩家站在方块上（方块有碰撞体）
- 左键推动活动方块（视线方向，3m范围）
- 右键清除已放置方块（需ClearBlockSkill）
