# 🧊 3D TETRIS — 立体俄罗斯方块

> 一款可爱风格的 3D 俄罗斯方块游戏 · Unity 2022.3 · 第三人称视角

---

## 🎮 游戏简介

**3D TETRIS** 将经典俄罗斯方块的逻辑延伸到三维空间。玩家以一个可爱角色置身于立体棋盘之中，通过移动、跳跃乃至飞行/喷射来与掉落的 3D 方块互动。

### 核心特色
- 🧊 **真正的 3D 方块** — 不仅仅是平面的延伸，而是立体的方块组合
- 👁️ **第三人称视角** — 如《糖豆人》《泡姆泡姆》般的沉浸体验
- 🎯 **多重消除逻辑** — XZ 面消除 / XY 面消除 / YZ 面消除，方块可拥有不同消除属性
- ⚔️ **实时 PvP 对战**（规划中）— 与好友同场竞技
- ✨ **技能系统**（规划中）— 喷射飞行、特殊消除等

## 📁 项目结构（规划）

```
├── _Art/               # 美术资源
│   ├── Characters/     # 角色模型
│   ├── Blocks/         # 方块材质

```
